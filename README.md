# 星茫沙的bot的查询器

基于某人的对涩涩的要求而诞生的多功能查询器

>[!警告]
>本插件含有r18功能，请仔细思考后再考虑使用，请勿在高频使用。（待会冲死了怎么办）
>
>如果你试图接入qq机器人，那么本插件会自动在群聊中禁用r18相关内容。


## 插件功能
**通过pid查询图片**
```
/p <pid>
```

**搜索或下载jm的本子**
>只输入以下代码查询详细功能分只
```
/jm
```

**南风图库接口图片**
>只输入以下代码查询详细功能分只
```
/nf
```

**萝莉图库接口图片**
>只输入以下代码查询详细功能分只
```
/loli
```

**栗次元图库接口图片**
>只输入以下代码查询详细功能分只
```
/LCY
```

**MirlKoi图库接口里的图片**
>只输入以下代码查询详细功能分只
```
/m
```

**查询mc服务器状态**
```
/mcs <服务器地址>
```

>[!!警告!!]该插件所有功能均未做异步处理，所有的下载类功能在使用时均会出现较长时间的等待。



## 支持库

- [jmcomic](https://github.com/hect0x7/JMComic-Crawler-Python)
