# 星茫沙的bot的查询器

基于某人的对涩涩的要求而诞生的多功能查询器

>[!警告]
>本插件含有r18功能，请仔细思考后再考虑使用。
>请勿在高频使用。（待会冲死了怎么办）
>如果你试图接入qq机器人，那么本插件会自动在群聊中禁用r18相关内容。


# 插件功能
[/p] - 通过pid查询图片
[/jm] - 搜索或下载jm的本子
[/nf] - 南风API图库接口里的图片
[/loli] - 萝莉API图库接口里的图片
[/LCY] - 栗次元图库接口里的图片
[/m] - MirlKoi图库接口里的图片
[/mcs] - 查询mc服务器状态


# 支持库

- [jmcomic](https://github.com/hect0x7/JMComic-Crawler-Python)
- [pyvips]【图片分割使用】
